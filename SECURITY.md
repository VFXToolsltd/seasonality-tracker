# Security

## Reporting a problem

If you believe you have found a security problem in Seasonality Tracker, please
report it privately rather than opening a public issue: via
[vfxtools.co.uk](https://vfxtools.co.uk).

Please include what you found, the version (shown in the app's **About** box) and
steps to reproduce it if you have them.

## What's in a build

The published builds are compiled applications only. They contain **no credentials
and no production data**, and they make **no network connections**: your settings
live in `~/.seasonality_tracker/` and your photos, footage and logs in the library
folder you choose — both on your own machines.

## Verifying a download

Every release ships a `SHA256SUMS` file; see *Verifying your download* in the
[README](README.md#verifying-your-download).

## Supported versions

Only the **latest** release is supported.
